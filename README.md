# Manees Thilagar — Full Stack Developer Portfolio

A modern, responsive React portfolio built with a dark cyberpunk aesthetic featuring cyan/blue tones.

## Features

- **Hero** — Typewriter role animation, floating avatar, social links
- **About** — Code block style bio, contact details
- **Skills** — 4 category cards + proficiency bars
- **Major Projects** — 3 MERN stack apps with GitHub links
- **Mini Projects** — All 12 mini projects in a grid
- **Contact** — Form with validation + direct contact links
- Sticky navbar, back-to-top button, cursor glow effect, subtle grid background

## Getting Started

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm start
```

Opens at **http://localhost:3000**

## Build for Production

```bash
npm run build
```

## Customization

All personal data is in **`src/data.js`** — edit your name, projects, skills, links there.

## Tech Stack

- React 18
- CSS-in-JS (inline styles)
- Google Fonts: JetBrains Mono + Outfit
